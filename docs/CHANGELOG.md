## Features

- **新版设置界面**：

  - 重做为功能分类的五大独立标签页，功能项按卡片分组
  - 支持自定义主色调、背景色、控件底色和文字色，修改后立即生效，并提供恢复默认主题
  - 新界面默认启用，可在通用页关闭回到旧版；折叠箭头改为左侧描边图标，取色器改为双列并支持输入 Hex 与恢复默认色，数字、滑条和颜色通道也可直接键入

- **自动更新**：

  - 默认关闭，可在通用页开启。开启后启动时检查一次版本，也可手动检查；发现新版本后显示横幅，支持手动或自动下载
  - 更新包经大小与 SHA-256 校验后暂存，重启游戏时在加载 Mod 前替换文件，失败会回滚
  - 更新条目按加载器区分，并可按游戏版本限制适用范围；Melon 包改为解压到游戏根目录，本体放入 `Mods`，更新组件 `TimingShow.UpdateBootstrap.dll` 放入 `Plugins`。缺少该组件时本体仍可加载，但更新入口会提示组件缺失
  - 横幅显示下载进度、错误以及重试/取消/稍后操作；

- **编辑器击打点面板**：

  - 开启编辑器击打点后按 F6 开合（可改键）。面板可拖动、缩放和调整宽度（宽度 240–460，缩放 0.75–2.5），支持按地板、时间、玩家、偏差与判定筛选或搜索，点击结果可固定并查看详情
  - 可只显示匹配项，也可压暗未匹配标记，并显示匹配数量；标记支持调整大小、透明度、形状和配色
  - 面板会拦截落在其上的鼠标输入，搜索框聚焦或拖动、缩放时也拦截键盘，F9/F10 始终放行
  - 新增「禁用输入钩子」开关（默认关闭），用于排查面板与游戏输入的冲突

- **日志记录与判定色带**：

  - 日志开始记录游戏难度和每击的判定窗口倍率，概览信息与上次会话报告会显示难度和窗口倍率。JSON 格式升至 v10，二进制格式升至 v11，旧日志的判定窗口倍率按 1 倍处理
  - 散点图判定色带默认按日志记录的游戏难度取阈值；关闭该选项或日志没有难度时回退到手动阈值，并计入窗口倍率
  - 新增「仅保存完整通关」选项（默认关闭），未通关、从检查点开始或练习模式的会话不再写入日志

- **日志图表增强**：

  - 散点图的偏移范围筛选支持设置最小/最大毫秒值（角度谱为度），可一键重置，并显示范围内的样本数
  - 散点图判定图例拆分为 XPerfect、Perfect、Early、Late、Miss、Other 六类，可单独开关，默认全部显示
  - 悬停详情新增「显示详细信息」开关，开启后显示地板编号、角度、BPM 和旋转方向
  - 日志窗口的范围输入框重写，支持光标定位、拖选、双击或三击选中、复制粘贴、撤销，以及 Enter/Tab 切换

- **判定版本兼容**：

  - 高级页新增判定版本选项：自动、旧版、r150 (3.4.0+)，并显示检测到与实际使用的版本
  - 无法识别判定版本时可按最接近的版本继续工作

- **性能与稳定性选项**：

  - 低开销模式跳过每帧字体解析，降低 HUD 开销
  - 图表重绘间隔可设为 0–1000 毫秒，0 为每帧
  - 补丁异常保护默认开启，会记录补丁内的未处理异常并继续渲染

- **Melon 加载器适配**：

  - 配置窗口改为自绘边框，底部新增缩放滑块；首次启动会提示设置菜单按键
  - 配置、日志、缓存和更新文件统一放到 `UserData/TimingShow`，旧 Settings.json 会自动迁移，旧版默认日志目录会切换到新位置；呼出按键改由 MelonPreferences 管理，可在游戏内绑定

## Improvements

- 日志窗口与设置面板改用羽化抗锯齿圆角、渐变和阴影绘制
- 新界面的日志页改为折叠列表，行内按钮按文字自适应宽度，搜索框加宽并显示占位提示，自动清理与保留数量合并到一行；工具栏新增「打开 Logs 文件夹」
- 颜色设置新增透明度（A）通道；日志窗口的设置面板新增「其他」页，包含自定义字体与路径、报告热键（默认 F10）、查看上次报告和重置按键
- 新增「自动设置语言」开关，开启后按系统语言切换界面；补齐并修正三语文案，删除未使用的键
- 「记录上次会话报告」与「编辑器击打点」默认关闭，需要时分别在通用页和替换显示页开启
- 移除「自动重载编辑器」选项；切换「替换判定显示」后无需重进场景即可生效
- 移除「低开销模式」：字体本已按设置缓存，该开关只省下每帧的字体键计算，HUD 改为仅在内容刷新时检查字体
- 性能报告改为打包为日志目录下 PerfLogs 的 tar.gz，新增绘图阶段、GC、内存分配与日志写入统计；
- 构建脚本按加载器分别生成 TimingShow.UMM.zip 和 TimingShow.Melon.zip，发布流程同步写入 Repository.json；新增 PR 构建与几何检查工作流，几何选择器检查覆盖 648 个用例
- 整理入口与游戏适配层：合并 UMM 的 Boot 与入口，生命周期统一到 ModEntry，游戏状态适配移入 Game/
- 散点图在非交互状态不再每帧重建网格，图表重绘间隔对散点图生效，降低游玩时的绘制开销
